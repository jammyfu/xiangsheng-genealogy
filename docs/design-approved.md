# 相声家谱：已确认的融合设计

用户于本轮确认融合设计，授权大幅重构、持续开发、每个里程碑提交并同步 Git。

## 视觉与体验

- 以已确认的山水长卷、世代谱系、人物书笺三幅设计为视觉依据；新增生平年表沿用同一风格。
- 暖白宣纸 #F8F5EE，墨色 #30332E，朱砂 #8B2626，灰青山水。文字使用本地宋体/书法字体。
- 页眉统一品牌、览谱/寻人/考据、人物搜索；其下固定四种浏览方式。桌面图谱右侧为人物摘要，书笺为对开阅读。
- 背景必须是真实水墨位图资产。关系图使用数据驱动的可缩放 SVG，属于精确信息表达，不以生成图替代真实关系。
- 四模式共享人物、检索与筛选，并在 URL 中保留；各图谱模式分别记住缩放和位移。
- 图谱按实际字辈对齐，支持分支展开、返回当前人物和键盘操作；不同师承说法不能强行简化为唯一树。
- 移动端单页阅读，图谱横向空间可平移，资料改为可展开抽屉。支持减少动态效果，不能阻塞用户操作。

## 内容与史料

- 保留已有105人，新增有来源人物及事件，公开来源覆盖程度，不声称全量核验。
- 分开记录组织退出、组织除名、师门除名、演出暂停、拜师、逝世、作品和争议。组织退出不能删除历史师承。
- 事件含时间与精度、人物、事实概述、来源、不同说法、核验状态、核验日期。新闻发布日期不冒充事件日期。
- 已报道事实、当事人说法、存在分歧、待核实分别展示。不得把多次转载当作多份独立佐证。
- 敏感叙述必须具名归因；只写公开专业经历，不扩展私人资料、侮辱性评价或未经证实的违法指控。
- 修正旧数据中没有依据的“后独立发展”等说法；有其他授艺经历本身不使正式拜师关系变争议。
- 音频不托管。只有作品标题时不显示虚假播放按钮。未知信息明确显示待补，不编造填空。

## 验收

测试覆盖状态保留、图谱关系和布局、事件来源/日期/人员引用。浏览器核验四模式、搜索、筛选、分支、史料详情、桌面与窄屏，保存设计对照截图和报告。
