# 聚焦文字云

保留山水长卷、人物选择、游径、缩放、静止阅读、全屏和人物书笺；新增默认的聚焦文字云，随时切回“原貌长卷”。

## 阅读规则

- 当前人物居中，真实师承链左师右徒；两侧按可用空间压缩，最近的老师优先。
- 点选师父时，右侧主横线优先展示资料明确的大弟子，再沿各代同样规则展开；主横线保留高亮，其他分支淡显并可悬停比较。未明确的大弟子不根据年龄、热度或弟子数量认定；仍采用普通支线选择策略，不标记为大弟子。阅读顺序配置仅作用于现有师承边。
- 多位老师按现有关系备注优先选择正式门户，技艺／开蒙及争议关系仍保留，可在外围与人物资料中查看。这只是显示优先级，不修改史料或关系。
- 主线竖排，外围横排。外围位置不表示字辈；红色为当前一脉，悬停保留原有青色比较与交集高亮。
- 屏幕空间不足时收纳次要姓名，不无限缩小。人名册包含完整目录，可按姓名、艺名搜索并定位。
- 按实际容器尺寸计算椭圆候选区，以姓名矩形做碰撞检测，避开主线与边缘工具栏；选择人物沿用平滑移动，静止阅读不强制动画。
- 小传和字辈调整直接显示在侧栏，较长补记折叠，完整人物书笺继续保留。

## 参考案例

- [yWorks：交互式局部过滤](https://www.yworks.com/pages/interactive-filtering-of-large-diagrams)：突出当前关系，保留可恢复的上下文。
- [Ancello 家谱浏览](https://www.ancello.com/)：保留熟悉的选择、缩放、适配与姓名定位入口。
