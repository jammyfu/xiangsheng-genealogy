# Ink Atlas Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task. Main agent integrates and commits milestones; independent assets, graph and evidence tasks may run concurrently in non-overlapping files.

**Goal:** 按已确认设计完成可切换相声家谱与有出处的事件档案。

**Architecture:** 保留 React/Vite 数据目录，新增统一 URL 浏览状态、2D 图谱、书笺和事件年表。数据与布局为纯函数，视觉和事实独立。

**Tech Stack:** React 19、TypeScript、Vite、SVG 数据图谱、Vitest、JSON Schema、Phosphor icons。

**Spec:** docs/design-approved.md

## Global Constraints

- 字辈：德、寿、宝、文、明；未知不用猜测。
- 保留历史人物及师承，不因退出/除名删除历史事实。
- 事件的参与者/来源引用必须存在；争议叙述具名归因。
- 每个里程碑验证后独立提交并推送 codex/ink-atlas-20260910；不强制推送。
