**检查条件与边界**

- 桌面浏览器窗口为 1363 × 936；记录的页面内容宽度为 1348。对照时按 1363 像素桌面窗口的宽度比例理解参考图，比较构图、层级、字体、色彩和控件位置。
- 手机检查使用实际尺寸为 390 × 844 的浏览器 iframe，页面内容宽度为 375；不是把桌面截图缩小。手机书笺的 DOM 测量为 `scrollWidth = 375`、`clientWidth = 375`。
- 曾尝试在 1586 像素宽的设计尺寸 iframe 中获取 `fullPage` 截图，该次捕获超时。未获得同尺寸整页图像差分，不声明像素误差阈值通过或与设计完全一致。
- 视觉复核查看了 `qa-scroll-hou.jpg`、`qa-tree-final.jpg`、`qa-book-final.jpg` 及手机长卷截图；归档截图见上表。较早截图中的局部控件状态，以最终代码和后续交互记录为准。
- 浏览器结果来自主执行流程；下表注明的 React/jsdom 检查由本轮独立执行。浏览器记录与组件检查的证明范围不同，未将 jsdom 当作真实手机浏览器。
