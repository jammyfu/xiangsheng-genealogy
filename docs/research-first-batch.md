# 首批人物与艺事史料核验

核验日期：2026-09-10。此批接入 11 条事件、10 条来源，新增曹云金、何云伟、杨九郎三个人物档案。目标是先建立可追溯的历史记录；不宣称人物或事件已经穷尽。

## 记录原则

- 组织退出、家谱除名、监管整改、公司行政处罚、内部暂停工作分开记录。历史上曾存在的师徒关系不因其后的除名从图谱删除。
- 日期采用来源能够支持的精度；报道发布日期存于来源说明，不替代实际事件日期。采访日期只有间接推算时，降到月份。
- `documented` 说明相关行动或发表行为有报道依据；`attributed` 说明其内容属于具名当事人陈述；`disputed` 并列双方具名、有出处的不同说法。
- 转载同一通报不算两条独立证据。新闻转引当事人长文只证明其公开陈述，不自动证明其中的费用、动机和指控。
- 人物的师承争议与其生活、组织或演出争议不是同一回事，不给人物整体贴负面标签。

## 本批修正的人物与关系

1. 原 `cao-heyang` 记录把“曹云金”写为曹鹤阳别名，并混入“后独立发展”、未经核实的出生年和争议标记。现分为两个独立人物，移除曹鹤阳记录中的错误信息。2025 年现场报道证实其当时随德云社参演；不据此断言 2026 年全部组织职务。
2. `hou-yaowen--guo-degang` 的师承已有报道支持。原先用张文顺等问艺经历作为争议依据不成立，撤去该边及郭德纲人物层面的对应争议标记。未添加无独立证据的杨志刚师承边。
3. 新增 `guo-degang--cao-yunjin`、`guo-degang--he-yunwei` 作为历史师承边，分别链接后来组织退出与家谱除名事件。
4. 杨九郎新增人物及郭德纲师承边暂据现有百科名录；官方通报只用于核验演出与整改事件，不冒充正式拜师日期的依据。沿用项目郭德纲为第八代、门下为第九代的布局约定，`generation: null` 不把“云鹤九霄”当传统字辈续字。
5. 本批没有给新人物补未经核验的出生年、传闻作品、私生活或所谓有罪结论。
