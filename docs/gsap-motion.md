# GSAP 与空间长卷的动效约定

用户要求动效符合交互习惯、过程清晰，并与真实3D配合。本轮在已有设计和操作上增加动效，不延迟路由更新、按钮选中或资料读取。

| 操作 | 动效与时长 | 用户看到的含义 |
| --- | --- | --- |
| 3D长卷首次就绪 | GSAP驱动实际曲面open参数，1.1秒，power3.out | 卷面从卷起至可读姿态；显示“长卷正在舒展 · 可直接拖动与选人” |
| 切换四种阅法 | 0.42秒，power2.out；书笺/年表按导航顺序轻移18px，图谱保持位置 | 新方式立即选中，过程显示“正在切换至…”；结束恢复当前人物说明 |
| 选取另一人物 | 人物摘要、书笺或年表轻移8px并显现，0.28秒 | 资料随所选人物更新；图谱点击目标不参与DOM位移动画 |
| 书笺资料标签 | 资料内容轻移6px并显现，0.28秒 | 标签选中立即改变，焦点继续遵循既有键盘逻辑 |
| 直接鼠标/拖动 | 保留3D指针阻尼和稳定锚点；不以GSAP延迟拖动 | 内容跟随手，悬停不会逃离指针 |

## 中断与可访问性

- 旧视图和资料动效随React生命周期清理，快速切换只保留最新目标，不排队播放。
- 减少动态偏好下呈现最终状态；系统偏好变化由GSAP matchMedia处理。3D静止阅读继续可用。
- 页面隐藏时UI过渡完成并清理位移，3D展开停止；已展开的长卷不会重复播放入场。
- GSAP只负责卷面展开参数，R3F不再同时写入该参数。每次更新调用invalidate，让真实几何和动画进度保持同步。
- 展卷替换使用完整killTweensOf，避免尚未初始化的旧动画留在时间线上。
- 透明度从0.65/0.7起步，内容在整个过程可辨认；不锁定按钮、不伪造加载进度、不滚动劫持。

## 本轮验证

117项测试、TypeScript和生产构建通过；新增6项验证覆盖实际GSAP中间值、单调展开、减少动态、重复/替换清理、导航方向、快速切换与最终样式恢复。

云端浏览器检查书笺师承标签，并连续切换年表→谱系→书笺：最终人物保持王谦祥，当前入口为人物书笺，data-transition恢复settled，主内容内联透明度/transform清空。最终截图检查未发现内容残留偏移或不可见。

现有云端浏览器仍禁用WebGL，因此本轮通过的是工程测试和DOM动效路径；真实GPU上展卷与人物纵深的联合观感、遮挡、移动端帧时间仍待验收。3D空间测试不等于GPU视觉验证。详见spatial-scroll-qa.md。

主入口gzip约152kB；3D异步模块gzip约176kB，仍有Vite的500kB模块体积提示。测试环境模拟Three导入时的重复实例提示仍存在。

官方实现依据：[GSAP context清理](https://gsap.com/docs/v3/GSAP/gsap.context()/)、[GSAP对象属性动画](https://gsap.com/docs/v3/GSAP/gsap.to()/)。
