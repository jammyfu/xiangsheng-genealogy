# 3D 水墨场景实现 · 2026-09-11

用户确认目标：docs/design/immersive-approved.webp，上半「岁月入画」、下半「一脉千枝」。本轮替换年表卡片轮播并新增立体世代谱系。既有山水长卷的卷曲交互继续保留。

## 已实现

- InkWorld：Three.js PerspectiveCamera / WebGLRenderer，时间轴与谱系共享环境与坐标投影。时间镜头沿 S 形路线移动，GSAP 1150ms power3.inOut，可中断。原生滑杆、前后按钮、拖动切换事件；默认不自动播放，不劫持滚轮。
- 有厚度和封口的曲面长卷 BufferGeometry；事件书笺为 BoxGeometry 与同坐标 HTML 标签；红色三维锚点和指向书笺的连接线。
- 谱系：有深度的球形节点、三维贝塞尔师承线、半透明世代分层面、可读的字辈标签。争议连线保持 LineDashedMaterial；700ms 连线展开。人物标签偏移到球形节点旁，避免盖住节点。
- 淡彩天空：2:1 全景贴图映射到内面天空球（天空穹顶，不是六面 cubemap / HDRI）。分层 RGBA 水墨山景平面、距离雾、半球光和方向光。
- 事件右侧固定详情、来源与不同说法，移动窄屏改为下方详情。世代谱系保留平面切换、展开支系、缩放、适应全图、键盘平移。
- 按需 requestAnimationFrame，DPR 上限 1.5，后台停止绘制，暂停/减少动态效果直接定位。分支更新复用 WebGLRenderer；场景切换清理几何、材质、贴图与事件监听。

## 数据边界

全部人物、事件和证据状态来自现有数据。没有把图中生成的人像、年份、辈分排序或参考文献当作事实入库。年表按事件序号间距排列，界面明确提示间距不代表历史时长。

## 验证

125 项自动测试通过，TypeScript 和 Vite 生产构建通过。新测试覆盖时间路径纵深、曲面厚度与有限法线、真实 Three.js 场景结构、透明材质、天空球、争议虚线、销毁资源、分支更新复用上下文与 WebGL 失败提示。场景测试仅替换 GPU renderer/texture I/O，几何和场景对象使用 Three.js；不是 GPU 渲染验收。

云浏览器已验证：年表前后切换、详情与出处一致、全部纪事、立体/平面谱系切换，以及桌面无水平溢出。

## 未通过的视觉验收

云浏览器仍禁用 WebGL。实际 GPU 中的曲面、透明遮挡、光照、雾效和最终与稿件相似度无法在此验收；云浏览器当前显示明确标识的简化投影预览。详见根目录 design-qa.md。

素材仍有少量浅色边缘；两次清边生成失去 alpha，未采用。天空左右接缝需真实 GPU 检查。当前山峦为透明平面分层，不是可全角度绕行的完整山体网格。尚未加入批准稿中的人物照片、可点击微缩地图及历史照片；图谱缩放/适应入口可用。移动实机性能、Safari 与完整无障碍验收待后续进行。
